Changes made:
The prior display-name sanitizer removed punctuation and Unicode: Deploy_Notepad++ was created as Deploy_Notepad while the app retained its full configured name. Consequently the management page filtered out the real GPO, OU orphan detection reported it missing, and reconciliation returned actual names that did not match the app configuration.
All GPO operations now use safely single-quoted, nonempty display-name literals, doubling apostrophes and rejecting control characters. A shared GroupPolicy resolver prefers case-insensitive exact matches, then the historical shortened name. Creation reuses an existing legacy GUID instead of making a duplicate; linking, unlinking, existence checks, deletion and startup-script removal resolve the same policy. No AD rename or data migration occurs on refresh. Configured names with a colliding legacy form prevent ambiguous fallback writes/reconciliation. Managed link enumeration reads GroupPolicy once, joins real gPLink GUIDs to the requested configuration names and retains those names in the returned map. Renderer management filtering/local counts and OU orphan detection use matching exact-first legacy rules. Invalid GPO JSON now reports an error instead of silently returning an empty successful list.
