Changes:
The updater displays and compares the fork release version 2.1 rather than the upstream semantic application version 1.2.11. Generator metadata retains the separate upstream version. Updater IPC exposes upstreamVersion separately from currentVersion.
Language dictionaries are refreshed after startup share configuration, before rendering release-check results and update dismissal dialogs, and whenever Settings are saved. Update banners and Settings rerender in the selected language, including when the saved language matches the configuration but the in-memory dictionary is stale. A remaining hard-coded share-restored toast now uses translations.
All remaining Spanish app-authored generated script comments and headers in built-in install templates and bundles are English. User-provided custom script content and configured installer language remain intact. Generator revision and bundle trackers advance to mod-rev-2.1 so existing generated scripts can be refreshed.
Application and bundle menus share viewport-aware placement. They open above their button when appropriate, clamp horizontally and vertically, limit width/height in small windows, allow scrolling within the menu and clean up their listeners on close, external scrolling, resize or replacement.
Removed standalone target-system diagnostic/test plans and their documentation references. Release documentation contains local automated check results and normal usage information.
Administrative workstation WinGet/catalog behavior is outside this revision's changes, as requested. No catalog, LDAP, GroupPolicy, installer scope or task registration behavior was changed.
